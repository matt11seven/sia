| --- | --- |
| Invocar uma skill | Skill |

| Rodar um comando | Bash |

| Achar arquivo | Glob |

| Chamar Supabase ou Vercel | o MCP ligado, pelo nome real |

Sem AskUserQuestion, ou em modo automático, a pergunta vai no chat, uma por vez.
