# Instalar no Codex

O manifesto do plugin que o Codex lê no mercado local está em `plugins/sia/.codex-plugin/plugin.json`. O mercado está em `.agents/plugins/marketplace.json`.

```bash
codex plugin marketplace add .
```

Depois, no Codex, abra `/plugins`, escolha SIA e instale. Sessão nova.

O bloco de hooks fica vazio, como no Superpowers para Codex. Quem acorda o loop é a description de `comecar`.

Prova: "Quero um site para marcar horários da minha clínica." A resposta entra em `entender` antes de qualquer arquivo de produto.
