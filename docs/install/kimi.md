# Instalar no Kimi

Instale no projeto que vai ser construído. Outro repositório fica sem o SIA.

O manifesto está em `.kimi-plugin/plugin.json`. Ele aponta as skills, pede a skill `comecar` no início da sessão e traz o mapa das ferramentas.

No Kimi, a partir da pasta do projeto que vai ser construído, aponte o instalador para o repositório do SIA (o mesmo caminho que aceita um repositório local). Sessão nova, aberta aqui. Se o instalador só oferecer escopo de conta, não use: isso acorda o harness em toda pasta.

Prova: "Quero um sistema que avisa quando o estoque acaba." A resposta entra em `combinar` só depois de `entender`, não cria arquivo de produto na primeira mensagem, e não abre tela.
