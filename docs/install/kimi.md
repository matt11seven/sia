# Instalar no Kimi

O manifesto está em `.kimi-plugin/plugin.json`. Ele aponta as skills, pede a skill `comecar` no início da sessão e traz o mapa das ferramentas.

No Kimi, instale esta pasta pelo instalador de plugins (o mesmo caminho que aceita um repositório local). Sessão nova.

Prova: "Quero um site para marcar horários da minha clínica." A resposta entra em `combinar` só depois de `entender`, e não cria arquivo de produto na primeira mensagem.
