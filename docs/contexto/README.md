# Contexto

Coloque aqui o que o sistema precisa respeitar e que já existe fora dele: planilha, exportação, documento da empresa, lista de preços, regra escrita.

O planejamento lê esta pasta antes de escrever o combinado. Número, nome e regra que estiverem aqui entram nesse texto, num briefing curto: o nome do arquivo e a frase do que passou a valer. A planilha não é copiada para lá. O que não estiver aqui não é inventado no lugar.

Estes arquivos ficam na sua máquina. Eles não vão para o Git, a menos que você peça.
